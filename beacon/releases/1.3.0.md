# Beacon Ruby v1.3.0

- **Breaking Security output:** distribute `beacon-security-0.2.0.gem` with SIEM v1
  envelopes as the only OTel Logs and diagnostic JSONL format. Parse `message` for
  complete serialized v2 evidence and dependency inventory. Fingerprint v1 is unchanged.
- Retain process identity and available trace correlation. Use invocation `span_id`,
  including request-entry spans; remove `server_span_id` and `current_span_id`.
- Default-filter `no_evidence` before export queue admission. Enable
  `BEACON_SECURITY_EXPORT_NO_EVIDENCE_ENABLED=true` to include it; unknown and
  suspected remain eligible. Include final escaped envelope bytes in budgets and
  multipart planning; preserve every inventory dependency exactly once.
- Pin Security specification `4a30f30e1027568cfbcf8661079a072fc89bd825` with schema
  v2, fingerprint v1, and wire profile `beacon-security-siem-v1`.
- Keep the adopted upstream baseline, upstream gem identities and experimental
  profiling 0.1.1 runtime unchanged. The previous published profiling gem is
  checksum-verified and reused without replacing its immutable artifact.

## Installation and migration

Download the source archive, Security 0.2.0, profiling 0.1.1, `SOURCE.txt`, and
`SHA256SUMS` from this Release. Follow the [versioned installation guide](https://github.com/beacon-observability/beacon-ruby/blob/v1.3.0/beacon/INSTALLATION.md).
These are GitHub assets, not RubyGems publication or a zero-code trace launcher.
Update consumers before upgrading. There is no legacy-output switch. Rollback
restores v1.2.1, Security 0.1.0 and the previous consumer together.

## Scope and limits

Security remains opt-in, approximate Rack/source-to-sink correlation on Linux
CRuby 3.3+. It is not exploit confirmation or assessed risk grading. Verified
actor/client IP remain empty; absent tenant uses `default`. Collector receipt
is not backend persistence. Profiling remains experimental and uses multipart
pprof with `OTEL_PROFILING_EXPORTER=http`; there is no OTLP Profiles claim.
Public artifact checks and exact source/CI evidence are recorded in the Release.
