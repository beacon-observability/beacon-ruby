# Beacon Ruby v1.2.1

Status: prepared for publication; this change does not publish a release.

## Changes

- Add `OTEL_PROFILING_EXPORTER=http` for the existing multipart/pprof uploader.
  Retain `datakit` and `pprof_http` aliases; reserve `otlp` for future protocol
  support. Sampling, encoding, endpoint precedence and file exports are unchanged.
- Publish the independently versioned `beacon-profiling-0.1.1.gem`, including its
  matching `profiler_version` tag. Security remains `beacon-security-0.1.0.gem`.
- Keep the adopted upstream baseline and upstream gem identities unchanged.

## Configuration and artifacts

```sh
export OTEL_PROFILING_ENABLED=true
export OTEL_PROFILING_EXPORTER=http
export OTEL_PROFILING_ENDPOINT=http://127.0.0.1:9529/profiling/v1/input
```

Planned GitHub assets are `beacon-ruby-1.2.1-source.tar.gz`,
`beacon-profiling-0.1.1.gem`, `beacon-security-0.1.0.gem`, `SOURCE.txt`, and
`SHA256SUMS`. This is source and GitHub gem distribution, not RubyGems publication.

## Validation and limits

See [candidate acceptance](../validation/profiling-1.2.1.md). Profiling remains
experimental on Linux CRuby 3.3+. Production overhead, other Ruby engines and
operating systems remain unqualified. The wire format is DataKit-compatible
multipart pprof; it is not OTLP Profiles. Security behavior is unchanged.

To disable profiling, set `OTEL_PROFILING_ENABLED=false` and restart. To roll
back, restore the checksum-verified v1.2.0 source and profiling gem 0.1.0, then
validate the application and receiver again.
