# Beacon Ruby v1.0.0

The initial Beacon Ruby source release preserves the complete official
OpenTelemetry Ruby Contrib source and history and establishes an independent
Beacon downstream. It is distributed through the fixed `v1.0.0` tag and the
`beacon-ruby-1.0.0-source.tar.gz` GitHub Release asset, with `SOURCE.txt` and
`SHA256SUMS` for source provenance and artifact verification.

## Source and Changes

- Official Contrib baseline: `opentelemetry-instrumentation-all/v0.99.0`, commit
  `e433edfa75c29dc1df223721bcbfbb4428f73e09`.
- Runtime instrumentation and upstream package identities are preserved. The
  Beacon source version does not renumber the individual `opentelemetry-*` gems.
- Three Net::HTTP connection-error tests use a deterministic socket error instead
  of relying on an external host. No runtime instrumentation behavior is changed.
- Inherited upstream workflows are archived outside the active workflow directory.
  No upstream publishing automation is enabled for Beacon.
- Development documentation, source synchronization guidance, a locked Collector
  smoke check, and locally installed spelling dictionaries support maintenance.

## Validated Scope

Validation covers Ubuntu 24.04 x86_64, CRuby 3.3.12, and Bundler 2.5.22:

- Shared instrumentation base: 51 tests, 68 assertions, no failures or errors,
  and 97.35% line coverage.
- Net::HTTP `dup`, `stable`, and `old` semantic modes: all three appraisals pass;
  combined line coverage is 100%. Skips in each run select the other modes.
- API 1.11.1, SDK 1.13.1, and OTLP exporter 0.37.0, with transitive dependencies
  pinned in `beacon/validation/Gemfile.lock`.
- OTLP HTTP/protobuf delivery to OpenTelemetry Collector Contrib 0.135.0 verifies
  service identity, HTTP client span kind, shared trace ID, and parent span ID.
- The selected component gems build and pass isolated installation and Collector
  checks. Repository formatting, lint, configured link, spelling, and source
  checks pass.

The release archive is checked against its source commit and accepted from an
extracted directory. The published assets are downloaded and checked again after
publication. See the
[versioned source installation guide](https://github.com/beacon-observability/beacon-ruby/blob/v1.0.0/beacon/INSTALLATION.md)
for download, checksum verification, smoke-test, and rollback instructions, and the
[versioned acceptance record](https://github.com/beacon-observability/beacon-ruby/blob/v1.0.0/beacon/validation/README.md)
for detailed component evidence.

## Limitations

This is a source release. It does not publish a Beacon gem on RubyGems, a prebuilt
agent, a zero-code preload, or a Beacon-owned container image. Upstream component
versions and licenses remain unchanged.

Rails, other framework and client integrations, other Ruby versions or engines,
other operating systems, DataKit, Metrics, Logs, Profiling, and Security are not
qualified by this release. Imported upstream code does not by itself establish
Beacon support. Checksums verify artifact consistency; this release does not claim
a signed software-supply-chain attestation.
